Verified defects and changes
1. src/services/ai.ts: removed automatic non-stream resend after ambiguous stream/network errors. One generation per call. Added AbortSignal and a default 300000 ms overall timeout; fetch and uni.request cancellation; no late chunk callbacks after abort.
2. src/services/ai.ts: SSE now buffers event frames (including multiline data, CRLF/CR, split UTF-8, final EOF frames), validates provider errors and completion markers, rejects empty/malformed/truncated/length-limited responses, and joins all Anthropic/Gemini answer parts while keeping Gemini thought parts separate. A JSON response to a stream request is parsed directly without replaying generation. Native Gemini URL preserves query parameters and distinguishes OpenAI-compatible routes.
3. src/config/aiConfig.ts and pages/settings/index.vue: validate provider, URL scheme, model and key requirements on read and write; trim values; reject corrupted configuration; support no-key custom/local/Ollama endpoints; clear prior provider key when switching providers; show persistence failures instead of claiming success. Settings clear failures are also handled.
4. pages/chat/index.nvue: current user input deduplicated against filtered request history, not the trailing waiting bubble; error/in-progress messages excluded; request reentry guard; restore the selected chart before building every request; preserve its own identity via chart agent's store/export changes. Added abort and late-result suppression on page unmount. Header archive actions disabled during generation. onLoad query type fixed for optional arguments.
5. features/agent/useAgentPage.ts: refreshed saved-config state on initialize/return, clearer unconfigured tip, all chart caches restored with ensureComputed, failed/in-progress responses excluded from later requests, request aborted on unmount, full profile passed into chart stores, timestamp zero accepted by execution checks.
6. features/agent/runtime.ts: explicit none stays none; malformed or truncated explicit actions never fall through to heuristic chart execution; inherited object keys rejected as navigation targets. Birth inference rejects lunar/ambiguous input and requires a time marker and valid minutes after a colon (9:?? is not 09:00); Chinese 12 AM maps to 00:00.
7. chat/ChatPanel.vue (scope later delegated by root): interrupted partial stream is marked error and retains the error explanation without dangling stream state; errors excluded from archives; auto-restore checks current messages/sending/disableAutoRestore again after async reads; manual archive operations and send are mutually exclusive.
