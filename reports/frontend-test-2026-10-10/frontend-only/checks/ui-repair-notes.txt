已确认并修复的问题
1. uni-view / uni-text 等自定义控件没有原生按钮的键盘行为。补充公共 h5Button：role、tabindex、disabled、Enter/Space、按住不重复、失焦取消、阻止当前激活键透传到刚打开的对话框。覆盖 Agent 发送/快捷提示/工具导航/待确认动作/思考展开、首页图标、用户菜单、紫微宫位放大及关闭。
2. 最初基于 event.currentTarget 的按键配对在真实 uni H5 失败：uni 每次事件都把 currentTarget 重新归一化为数据对象。改为使用实际焦点 DOM 元素配对；组件测试已升级为安装版本 @dcloudio/uni-h5-vue 的运行时及真实 $nne 事件归一化逻辑，重现失败后转绿。用户菜单保持“AI 设置 / 历史记录 / 关于”及纯前端本地路由；Escape/背景点击关闭，关闭后恢复触发器焦点。
3. Agent 发送/确认动作增加真实处理函数门禁，防止空白、生成期间、重复提交通过 textarea confirm 或其他事件绕过；补充图标可访问名称及焦点样式。宫位提供明确的“放大”动作，展开状态隐藏重复入口，长小限文本可换行。
4. ChatPanel 使用 input 文件选择后取消时，原 Promise 不结束，archiveBusy 一直为 true，后续保存和发送失效。现在 cancel 和空文件 change 都抛出 AbortError；恢复操作 finally 释放锁；取消静默保留现有对话，不意外回退到旧本地备份；有效文件选择仍正常恢复。
5. 紫微详情原先放在 .page-card 内，其 card-rise 动画保留 transform，导致 position:fixed 相对卡片定位。390×844 实测关闭按钮在视口外。H5 改用 Teleport to body，弹层 CSS 不再依赖卡片祖先；宽度限制在扣除 16px 边距的可用区域，高度限制为视口减 32px，内容区可纵向滚动。打开时聚焦“关闭宫位详情”，支持 Escape、Enter/Space 关闭，Tab 保持在唯一交互控件，关闭恢复原放大触发器焦点。未改全局页面动画。
6. 删除 UserAvatarDropdown 无用 email 变量；Timeline 删除 defineProps/defineEmits 编译宏的重复导入。
