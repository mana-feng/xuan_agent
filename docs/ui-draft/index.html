DESIGN NOTES · 2026.10.12

让探索更自然地发生

基于当前用户端源码与仓库截图的 UI 审视。保留八字、六爻、紫微、AI 对话和历史记录能力，重点优化信息层级与操作路径。当前项目未启动真实前后端，本页是一份独立的 HTML 交互草稿。

P1 / 首屏主任务

让用户先表达，再选择工具

现状：工具、快捷指令、对话依次排列，输入框位于页面后部。
草稿：将输入框提升到首屏，快捷问题缩为轻量提示，工具卡片放在其后。

pages/agent/index.nvue
components/agent/AgentConsolePanel.vue
P1 / 导航与任务连续性

在任何页面，都知道下一步在哪

现状：全局头部主要为图标与账户入口，主要工具依赖首页进入。
草稿：桌面侧栏、手机底栏固定呈现核心功能；结果页直接连接保存、编辑与继续提问。

components/yx-nav-header/yx-nav-header.vue
components/layout/PageScaffold.vue
P1 / 操作层级

一个入口，只强调一个动作

现状：每张工具卡片都有标签、解释和两个按钮；日期选择也使用强渐变按钮。
草稿：工具整卡可点击，输入保持朴素；仅发送、查看结果、保存等推进动作使用主色。

components/agent/AgentToolPanel.vue
pages/index/index.nvue
P2 / 视觉一致性

减少容器层级，让内容更安静

现状：页面卡片、区块与工具卡片层层嵌套，多个样式文件重复定义圆角、阴影与渐变。
草稿：使用可切换的渐变主题，在品牌、标题与主按钮上集中呈现，浅色背景光晕与细边线分区；宋体只用于品牌与大标题，正文维持易读的无衬线字体。

styles/page-patterns.css
P2 / 阅读与响应式

表单按组填写，结果按层阅读

草稿：表单包含清楚的标签、历法切换与日期输入；命盘表格和解读分开。桌面充分利用横向空间，手机改为单列和固定导航，保留键盘焦点与触控空间。
