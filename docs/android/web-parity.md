## 审查修正

独立只读审查发现两项 P2：新盘误用旧记录编号、异步计算完成后覆盖新模块。已分别引入显式编辑身份与计算代次；补充更新原盘/新建第二盘/切页途中计算的设备回归。复审确认这两条路径修正，无新增 P1/P2；复审不替代设备运行。

流式连接中断或取消时，已收到的正文会保留并标记未完成；存储失败仍提供仅保存重试，不重复 API 请求。此前的大 SQLite 记录分块读取、事务导入和密钥加密保持不变。

## 仍有差异或未验证

- 不是逐像素复制，使用 Android 原生控件；字形、键盘、系统栏和手势遵循系统。其他尺寸/字体缩放和 API26 最低版本尚未逐一验收。
- 八字完整流月节令数据到 2101；更晚流年明确提示流月/日/时不可用，不生成占位盘。
- 历史页排盘与对话分组；对话模型没有公开更新时间字段，不能跨两组按时间完全混排。
- AI 展示流式正文，未提供网页的模型思考内容折叠展示；真实服务商连接、弱网、真实网络取消/断流 NOT_EXECUTED。
- 继续使用原生 v1 备份（8 MB、事务合并），不直接导入浏览器旧 JSON。密钥不进入备份。
- 未保存草稿保留于 ViewModel，可跨实际 Activity 重建；未承诺系统杀进程后的草稿恢复。
- HTTPS-only 保持不变，Ollama 需要 HTTPS 入口。
- debug 侧载测试包，未完成生产签名/商店上架验收。
