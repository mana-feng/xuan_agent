# 本次实现取舍与边界

| 决定 | 理由 | 代价/边界 |
| --- | --- | --- |
| 直接在android独立worktree开发，保留frontend源码基准 | 用户指定分支，避免混入main未提交修改 | 分支保留前端参考文件，Android工程在android-app |
| Kotlin全原生；固定离线历法和静态规则表 | 用户指定语言，保持现有历法规则和来源 | 输入范围1900—2099；不是整盘预存；跨版本系统时区数据库仍有差异可能 |
| 使用SQLiteOpenHelper代替建议过的Room | 现有工具链可直接构建，实际事务/恢复已验证 | 未来schema升级需编写迁移；没有宣称Room实现 |
| 固定已安装JDK21/Gradle8.5/AGP8.2.2/SDK34 | 可重复的本地构建和验收 | 仅debug侧载，不代表满足当前商店目标SDK政策 |
| HTTPS-only | 自动审批拒绝全局明文HTTP例外后采用安全替代 | 不支持纯HTTP局域网模型地址，需HTTPS入口 |
| 原生备份v1；全量校验后事务合并 | 保持结果和规则快照，避免部分导入 | 不直接导入旧浏览器档案；同编号替换；8MB单份上限，支持分项导出 |
| 草稿由ViewModel保留 | 保留切页/实际旋转的农历与输入、避免错误重解释 | 不承诺操作系统杀进程后恢复未保存草稿；正式记录和会话是SQLite持久化 |
| 已收到AI回复先显示再持久化；仅保存重试 | 写盘失败不能丢弃已获取回复或重复付费 | 存储失败后需用户重试保存/导出；发送与切换受保护 |
| 结构性八字结果，保留逐柱神煞与关系 | 不把通用/不可靠评判当作验证事实 | 不移植自动强弱喜忌/格局和额外流运节点图等扩展函数 |
| Agent建议点击确认，普通AI回复整段显示 | 参数可审阅，允许列表严格验证 | 无流式展示或聊天内聚焦紫微宫位 |
| 只声明已运行的证据 | 构建/对照/模拟器/真实模型/实体机分别记录 | 真实API与真机未执行，不能据模拟器或样本数量外推全面正确性 |

代码审查提出的4项重要问题和命名问题均已处理并验证。未修饰的独立审查快照、实现者修复记录和最终验收并存；没有再次付费派发整分支复审。4条Lint警告保留在验收记录中，未通过抑制将其伪装消失。
